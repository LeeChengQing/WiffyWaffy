# Wiffy Waffy menu product photos

- `assets/products/<product-id>.webp` contains the 640 × 640 WebP shown in menu cards.
- `assets/products/4k/<product-id>.webp` contains the 4096 × 4096 WebP shown in product details.

The nine Top Picks and Seoul photos come from the supplied waffle crops. Each waffle is centered with padding and upscaled with Lanczos and mild sharpening. The source resolution limits fine detail.

The Classic card and its alternate photo use the original menu poster assets. The Classic picker uses its interactive flavour preview.
